# Atlas — Dashboard financeiro

Demo estática e standalone de um dashboard financeiro fictício.

## Recursos
- Tema off-white e laranja, responsivo.
- Seletor de período que atualiza KPIs e gráfico SVG.
- Busca de movimentos e exportação CSV local.
- Dados exclusivamente fictícios; sem backend, login, coleta ou armazenamento.

Abra `index.html` em um navegador moderno.
